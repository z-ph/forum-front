# 对接后端 API — 实施计划（分两期）

## 分期原则

**第一期**：让论坛"可读可登录"——API 基础设施 + 认证 + 首页浏览 + 详情阅读
**第二期**：让论坛"可写可管理"——发帖/编辑/回复/管理后台 + 全面打磨

---

## 第一期：核心浏览链路（P0）

### 目标
用户能访问首页、浏览帖子列表、查看详情、登录/注册。

### 任务及依赖顺序

```
第 1 步（无依赖，可并行）
├── 任务 01：API 服务层（31 个接口全部封装）
├── 任务 02：类型定义重构（api.ts + 转换函数）
├── 任务 03：Service 入口（forumService.ts）
└── 任务 11：环境配置与代理（proxy + .env）

第 2 步（依赖 01-03）
└── 任务 04：Hooks 层适配（替换 mock 导入，新增 useCurrentUserQuery 等）

第 3 步（依赖 04）
├── 任务 09：用户认证（登录/注册/退出/token 管理）
└── 任务 05：首页数据流重构（分类树 + 标签 + 帖子列表并发加载）

第 4 步（依赖 04-05）
├── 任务 06：主题帖详情页适配（分页回复加载）
└── 任务 12：路由守卫与权限控制（token 检查、401 拦截）

第 5 步（依赖 09）
└── 任务 13：错误处理（部分：网络错误、401、code≠0）
```

### 第一期交付物与验证标准

| 验收项 | 预期结果 |
|--------|---------|
| 首页加载 | 展示分类树、标签列表、帖子分页列表，各自独立 loading |
| 分类筛选 | 点击父/子分类，帖子列表按分类刷新 |
| 帖子详情 | 展示帖子内容 + 顶层回复分页，展开子回复 |
| 用户注册 | 填写 email/username/nickname/password → 自动登录 → 跳首页 |
| 用户登录 | email/password → 跳首页，右上角显示昵称 |
| 退出登录 | 清除 token → 显示"登录"按钮 |
| 页面刷新 | token 持久化，自动恢复登录状态 |
| 401 处理 | token 过期 → 清除 token → 弹提示 → 跳登录页 |
| 代理配置 | API 请求正确转发到后端，无 CORS 错误 |

---

## 第二期：完整 CRUD + 管理功能（P1-P3）

### 目标
实现完整的发帖/编辑/删除、回复层级、分类/标签 CRUD、管理员功能。

### 任务及依赖顺序

```
第 1 步（依赖第一期 04）
├── 任务 07：分类管理适配（侧边栏树形渲染 + CUD）
├── 任务 08：主题帖发布/编辑适配（tagIds、分类级联）
└── 任务 10：回复层级支持（回复回复、子回复折叠）

第 2 步（依赖第 1 步）
└── 任务 14：组件兼容性检查（逐一验证 8 个组件）

第 3 步（依赖全部）
├── 任务 13：错误处理（补全：空列表、并发错误隔离、null 防御）
└── 任务 15：端到端测试验证（完整用户行为路径）
```

### 第二期交付物与验证标准

| 验收项 | 预期结果 |
|--------|---------|
| 发帖流程 | 选分类（两级级联）→ 选标签（多选）→ 写内容 → 提交 → 跳详情 |
| 编辑帖子 | 预填数据 → 修改 → 提交 → 详情更新 |
| 删除帖子 | 确认弹窗 → 删除 → 跳首页，列表不显示 |
| 回复主题帖 | 底部输入 → 提交 → 顶层回复列表刷新 |
| 回复评论 | 点击"回复"→ 内嵌回复框 → 提交 → 子回复列表刷新 |
| 分类管理 | 新增/编辑/删除分类，树形结构正确刷新 |
| 标签管理 | 新增/编辑/删除标签 |
| 管理员操作 | 用户分页查询、启用/禁用用户、隐藏/显示帖子 |
| 我的帖子 | 分页展示当前用户帖子 |
| 我的回复 | 分页展示当前用户回复 |
| 空状态 | 无帖子/无回复时展示"暂无数据" |
| 错误隔离 | 单个接口失败不影响其他模块 |

---

## 实施建议

1. **第一期完成后即可部署测试**，验证用户浏览和认证链路
2. **切换策略**：第一期在 hooks 层将整体导入从 `forumMock` 切换到 `forumService`，保持 `forumMock.ts` 仍在仓库中，方便后续调试比对
3. **回归测试**：第二期每个写操作完成后，回归验证对应的读链路（如发帖后验证首页列表和详情页是否正确展示）
