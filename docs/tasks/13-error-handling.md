# 任务十三：错误处理与边界情况

## 说明
mock 中的错误处理较简单，对接真实后端后需处理各种异常情况。

## 检查点

- [ ] axios 拦截器统一处理网络错误（Network Error）和超时
- [ ] 后端返回 `code !== 0` 时，在 mutation 的 onError 中展示后端 `msg`
- [ ] 分页接口返回空列表时展示"暂无数据"空状态
- [ ] token 过期（401）时自动跳转登录页并提示"登录已过期，请重新登录"
- [ ] 表单提交失败时保持用户输入内容（不清空表单）
- [ ] 并发请求错误隔离：首页加载时某个接口失败不影响其他接口的数据展示
- [ ] 处理后端字段可能为 null/undefined 的情况
