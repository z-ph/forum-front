# 任务十五：端到端测试验证清单

## 用户流程

### 认证
- [ ] **注册**：填写 nickname/username/email/password → 提交 → 提示成功 → 自动登录 → 跳转首页 → 右上角显示用户昵称
- [ ] **登录**：填写 email/password → 提交 → 提示成功 → 跳转首页 → 显示用户信息
- [ ] **退出**：点击退出 → 清除 token → 右上角显示"登录"按钮
- [ ] **token 持久化**：刷新页面 → 自动恢复登录状态（调 /user/me）
- [ ] **token 过期**：清除 token → 发帖时提示登录过期 → 跳转登录页
- [ ] **注册失败**：重复 email → 后端返回错误 → 前端展示错误消息 → 表单内容保留

### 分类
- [ ] **查看分类**：首页侧边栏展示两级分类树
- [ ] **按分类筛选**：点击父分类 → 帖子列表按 parentId 筛选；点击子分类 → 按 categoryId 筛选
- [ ] **新增分类（管理员）**：填写名称/描述/选择父分类 → 提交 → 分类树刷新
- [ ] **编辑分类（管理员）**：修改名称/描述 → 提交 → 分类树刷新
- [ ] **删除分类（管理员）**：确认删除 → 分类树刷新 → 该分类下帖子不受影响

### 标签
- [ ] **查看标签**：获取并展示全部标签
- [ ] **新增标签（管理员）**：填写名称 → 提交
- [ ] **编辑标签（管理员）**：修改名称 → 提交
- [ ] **删除标签（管理员）**：确认删除 → 提交

### 主题帖
- [ ] **发帖**：选择分类 → 选择标签 → 填写标题和内容 → 提交 → 跳转详情页
- [ ] **查看详情**：进入详情页 → 展示主题帖信息 + 顶层回复列表（分页）
- [ ] **分页浏览**：帖子列表滚动到底部或点击"加载更多" → 加载下一页
- [ ] **筛选**：按分类/标签组合筛选 → 列表更新
- [ ] **编辑帖子**：进入编辑页 → 预填已有数据 → 修改 → 提交 → 详情页更新
- [ ] **删除帖子**：确认删除 → 跳转首页 → 列表不显示该帖子
- [ ] **查看我的帖子**：进入个人中心 → 展示当前用户发布的帖子（分页）

### 回复
- [ ] **回复主题帖**：在底部回复框输入 → 提交 → 顶层回复列表刷新，显示新回复
- [ ] **回复回复**：点击某回复的"回复"按钮 → 输入内容 → 提交 → 子回复列表刷新
- [ ] **查看子回复**：点击"展开 X 条回复" → 子回复列表展开
- [ ] **删除回复**：点击删除按钮 → 确认 → 回复列表刷新
- [ ] **查看我的回复**：进入个人中心 → 展示当前用户的回复列表（分页）
- [ ] 新增回复后，帖子列表中的回复计数更新

### 管理员
- [ ] **用户管理**：分页查询用户列表 → 展示 username/email/role/status
- [ ] **启用/禁用用户**：切换用户 status → 提交 → 列表更新
- [ ] **隐藏/显示帖子**：修改帖子 status → 帖子在列表中显示/隐藏
- [ ] **分类 CRUD**：完整增删改查流程
- [ ] **标签 CRUD**：完整增删改查流程
