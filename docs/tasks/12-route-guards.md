# 任务十二：路由守卫与权限控制

## 说明
当前无路由守卫，所有页面公开访问。后端有 Bearer token 认证。

## 适配内容

- 全局 router guard 检查 token
- 区分公开页面和需登录页面
- ADMIN 角色专属管理入口

## 检查点

- [ ] 全局 router guard：访问需要登录的页面时检查 token，无 token 重定向到 `/auth`
- [ ] 需要登录的页面：发帖页（如单独页面需要）、个人中心、管理后台
- [ ] 首页和详情页无需登录可浏览，但发帖/回复按钮需要登录
- [ ] 组件层判断：未登录时发帖/回复按钮提示"请先登录"
- [ ] ADMIN 角色的用户可见管理入口（用户管理、分类管理等）
- [ ] 401 拦截：axios 响应拦截器中统一处理，清除 token 并重定向
