# VEX 中文官方论坛功能模块归纳

## 一、功能模块总览

当前已确认的功能模块可归纳为以下 8 类：

1. 内容浏览与发现
2. 分类与信息架构
3. 帖子阅读与讨论
4. 问答与解决方案
5. 个人工作台
6. 通知系统
7. 社区与身份体系
8. 站点说明与治理

## 二、功能模块明细

### 1. 内容浏览与发现

用于帮助用户快速找到内容、跟踪更新和回到高价值话题。

- 首页类别总览
- 全站最新话题流
- 分类内最新话题流
- 排行榜视图
- 标签聚合页
- 站内搜索
- 帖子底部相关推荐

已确认的页面表现：

- 首页支持在 `类别 / 最新 / 排行榜` 之间切换。
- 分类页支持查看当前分类中的最新话题和排行榜。
- 帖子详情页底部提供“新话题和未读话题”推荐列表。

### 2. 分类与信息架构

用于组织论坛内容，降低用户定位问题和资料的成本。

- 一级论坛分区
- 二级子分类
- 分类筛选
- 子分类筛选
- 标签筛选
- 登录后的可配置边栏

已确认的一级分区包括：

- 官方发布
- 无分类话题
- 123论坛
- GO论坛
- IQ论坛
- V5论坛
- VEX EXP
- PRO论坛
- 赛事信息

已确认的典型二级分类包括：

- 一般话题
- 硬件问答
- 软件交流
- 制作炫酷
- 竞赛话题
- 官方发布

登录后新增的结构能力：

- 编辑边栏类别
- 编辑边栏标签
- 添加自定义版块

### 3. 帖子阅读与讨论

用于承载用户发问、回答、讨论和资料沉淀。

- 主题帖浏览
- 楼层式回复
- 帖子时间线
- 单帖回复
- 主题级回复
- 点赞
- 分享
- 复制帖子链接
- 书签
- 图片附件浏览

已确认的帖子页元素包括：

- 主题标题
- 所属分类
- 楼层序号与时间线
- 作者信息
- 正文内容
- 图片附件
- 单帖操作区
- 主题底部操作区

登录后可见的讨论操作包括：

- 回复整帖
- 回复某一楼层
- 点赞帖子
- 复制帖子链接
- 将帖子加入书签
- 分享主题

### 4. 问答与解决方案

该论坛不仅是普通讨论区，也具备明显的问答型社区能力。

- 话题“已解决 / 未解决”状态
- 解决方案标记
- 原问题帖中的解决方案摘要回链
- 回答质量和活跃度判断信息

已确认的问答机制表现：

- 话题标题处会显示“此话题已有解决方案”。
- 被采纳的回复会显示“解决方案”标记。
- 原帖中会展示“已由某用户在帖子 #n 中解决”的摘要区块。

### 5. 个人工作台

用于管理用户自己的内容、状态和偏好。

- 我的帖子
- 个人资料
- 书签入口
- 通知总页
- 话题通知级别设置

已确认的个人入口包括：

- `我的帖子`
- `个人资料`
- `查看所有通知`

已确认的订阅/提醒能力包括：

- 主题通知级别设置
- 邮件通知模式提示

### 6. 通知系统

用于承接站内互动反馈，帮助用户回到相关内容。

- 所有通知
- 回复通知
- 获赞通知
- 书签通知
- 其他通知

已确认的通知菜单标签包括：

- 所有通知
- 回复
- 赞
- 书签
- 其他通知
- 个人资料

已确认的通知能力包括：

- 通知列表预览
- 点击通知直达相关帖子
- 查看所有通知

### 7. 社区与身份体系

用于呈现社区成员、角色关系和活跃状态。

- 用户目录
- 用户个人资料页
- 群组
- 徽章
- 版主身份标识
- 发帖角色标识

已确认的身份信息表现包括：

- 原始发帖人
- 最新回复人
- 频繁参与者
- 已被接受的回答者
- 版主标识

### 8. 站点说明与治理

用于解释站点规则、论坛用途和社区协作边界。

- 关于页
- 常见问题解答
- 分类说明
- 特定分区规则说明

已确认的治理类入口包括：

- 关于
- 常见问题解答

已确认的规则说明示例：

- 各论坛大类和子类均带有用途描述。
- `赛事信息` 为公告型分区，说明中明确“不设置回复功能”。
