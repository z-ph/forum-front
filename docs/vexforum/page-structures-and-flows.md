# VEX 中文官方论坛页面结构与交互流程

## 一、首页结构与流程

首页是论坛的总入口，承担“找板块”和“看最新动态”两类任务。

### 页面结构

```text
首页
├─ 顶部导航
│  ├─ Logo
│  ├─ 搜索
│  ├─ 导航菜单
│  └─ 通知和帐户
├─ 页面主标题
│  └─ 所有类别
├─ 顶部筛选与切换
│  ├─ 类别筛选
│  ├─ 标签筛选
│  ├─ 类别
│  ├─ 最新
│  └─ 排行榜
├─ 分类总览区
│  ├─ 一级分类
│  ├─ 分类说明
│  ├─ 子分类链接
│  └─ 话题数量
├─ 最新话题区
│  ├─ 作者
│  ├─ 标题
│  ├─ 所属分类
│  ├─ 回复数
│  └─ 最后活动时间
└─ 页脚
```

### 核心交互流程

```text
进入首页
→ 浏览分类总览
→ 选择某个一级分类
→ 进入分类页
→ 查看该分类中的具体话题
```

```text
进入首页
→ 查看最新话题流
→ 点击某条话题
→ 进入帖子详情页
→ 阅读正文和回复
```

```text
进入首页
→ 点击标签或使用筛选
→ 缩小内容范围
→ 进入更具体的话题列表
```

## 二、分类页结构与流程

分类页用于承接某一论坛主题下的内容浏览，是“找具体问题”的主战场。

### 页面结构

```text
分类页
├─ 顶部导航
├─ 分类标题
│  └─ 如“V5论坛中的最新话题”
├─ 筛选区
│  ├─ 当前分类
│  ├─ 子类别筛选
│  ├─ 标签筛选
│  ├─ 最新
│  └─ 排行榜
├─ 话题表格
│  ├─ 话题标题
│  ├─ 所属子分类
│  ├─ 发帖人/参与者
│  ├─ 回复数
│  ├─ 浏览量
│  ├─ 活动时间
│  └─ 解决状态
└─ 分页/继续浏览
```

### 核心交互流程

```text
进入分类页
→ 根据子类别筛选
→ 根据标签进一步筛选
→ 浏览话题表
→ 按标题进入具体帖子
```

```text
进入分类页
→ 按“回复 / 浏览量 / 活动”理解内容热度
→ 优先打开高活跃或已解决话题
→ 获取答案或继续参与讨论
```

## 三、帖子页结构与流程

帖子页是最核心的内容消费和互动页面，也是论坛问答能力最完整的体现。

### 页面结构

```text
帖子页
├─ 顶部导航
├─ 帖子头部
│  ├─ 标题
│  ├─ 解决状态
│  └─ 所属分类
├─ 时间线区域
│  ├─ 发帖日期
│  ├─ 楼层进度
│  └─ 回复节点
├─ 帖子正文区
│  ├─ 作者信息
│  ├─ 正文内容
│  ├─ 图片/附件
│  ├─ 解决方案摘要
│  └─ 单帖操作区
├─ 回复区
│  ├─ 各楼层回复
│  ├─ 解决方案回复
│  └─ 互动按钮
├─ 主题操作区
│  ├─ 分享
│  ├─ 加入书签
│  ├─ 回复
│  └─ 通知级别
├─ 推荐内容区
│  └─ 新话题和未读话题
└─ 页脚
```

### 核心交互流程

```text
进入帖子页
→ 阅读原始问题
→ 查看是否已有解决方案
→ 跳转到被采纳回复
→ 获取结论
```

```text
进入帖子页
→ 浏览回复链
→ 点赞有价值回复
→ 收藏主题
→ 回复整帖或回复某层
```

```text
进入帖子页
→ 调整通知级别
→ 持续跟踪后续回复
→ 通过通知回流到该话题
```

## 四、登录后通知与账户流程

通知与账户入口是登录后最重要的个人状态入口。

### 页面结构

```text
通知和帐户面板
├─ 通知标签
│  ├─ 所有通知
│  ├─ 回复
│  ├─ 赞
│  ├─ 书签
│  └─ 其他通知
├─ 个人资料标签
├─ 通知列表
└─ 查看所有通知
```

### 核心交互流程

```text
点击“通知和帐户”
→ 查看通知分类
→ 打开某条通知
→ 跳转到相关帖子
→ 继续阅读或回复
```

```text
点击“导航菜单”
→ 进入“我的帖子”
→ 回看自己参与过的话题
→ 继续管理或参与讨论
```
